# 明日方舟桌宠

Windows 桌面陪伴应用。让干员在桌面走动、回应触摸、使用家具休息，并通过陪伴、招募、线索和派遣收集更多干员与形象。

## 主要功能

- **桌面互动**：点击回应、拎起拖动、自主走动和待机休息；可贴靠屏幕边缘，语音字幕自动避让屏幕边界。
- **干员与形象**：按名称、职业、星级搜索筛选，区分已拥有与本地已下载；查看立绘、预览小人模型，使用源石购买皮肤。
- **语音与字幕**：触摸回应、待机交谈、任命助理语音及对应原作台词；可选普通话、日语、英语、韩语，以干员实际提供的语音为准。
- **关系与信赖**：陪伴积累信赖与源石，查看关系进度、分配信赖储备，解锁并查看语音册。
- **招募与线索**：八职业寻访，可设置指定五星、六星 UP；集齐七类线索后，从每日两名六星候选中随机获得一名。重复干员转为通用凭证。
- **派遣探索**：在可拖拽、缩放的泰拉地图上选择地区，编入 1～3 名已有干员出发，获得货币、线索和家具奖励；派遣可离线完成。
- **家具试摆**：浏览主题与单品，筛选已有椅床，使用当前干员试坐、试躺；微调接触位置、尺寸和朝向，再应用到桌面。
- **凭证商店**：按主题购买尚未拥有的椅床，每件 100 通用凭证，已有部分不重复收费；月店可兑换合成玉。
- **偏好与缓存**：调整大小、置顶、自主走动、免打扰、语音和音效音量；管理素材下载、缓存清理及保存位置。
- **可选输入收益**：有效键鼠输入可积累合成玉，默认关闭；仅保存次数汇总，不记录输入内容。

## 怎么用

1. 首次进入“关系”页，自选一名干员；之后通过招募或线索交流获取更多干员。
2. 左键点击互动，按住拖动位置；右键打开功能菜单，选择干员、家具、派遣或设置等页面。
3. 预览不会替换桌宠，点击“应用”后才生效。页面左上返回或 Esc 关闭页面，不退出桌宠。

首次准备图片、模型和语音需要联网；已缓存素材可离线使用。存档与设置保存在本机，清理素材缓存不会清空已拥有干员和游戏进度。

## 从源码运行

需要 Windows、Bun 和 Node.js 24 或更新版本。

```sh
bun install
bunx install-electron
bun run prepare:assets
bun run build
bun run start
```
